# Java Tasks – Exercícios de Programação Básica

Este repositório contém uma série de pequenos exercícios desenvolvidos em Java com o objetivo de praticar conceitos básicos da linguagem, como entrada de dados, estruturas de repetição, condicionais e operações matemáticas simples.

## Lista de Tarefas

### `Task_1.java` – Exibir Mensagem Simples  
**Descrição:** Exibe a mensagem `"Olá, mundo! Essa é minha primeira task em Java."` no terminal.  
**Conceitos aplicados:** Impressão na tela com `System.out.println()`.

---

### `Task_2.java` – Somar Dois Números  
**Descrição:** Solicita ao usuário dois números inteiros e exibe a soma entre eles.  
**Conceitos aplicados:** Entrada de dados com `Scanner`, operações aritméticas.

---

### `Task_3.java` – Contagem de 1 até 5  
**Descrição:** Realiza a contagem de 1 até 5 utilizando três tipos de laços: `for`, `while` e `do-while`.  
**Conceitos aplicados:** Estruturas de repetição (`for`, `while`, `do-while`).

---

### `Task_4.java` – Verificar se Número é Positivo, Negativo ou Zero  
**Descrição:** Solicita ao usuário um número inteiro e informa se ele é positivo, negativo ou igual a zero.  
**Conceitos aplicados:** Condicionais (`if`, `else if`, `else`).

---

### `Task_5.java` – Calcular Média de 3 Notas  
**Descrição:** Solicita três notas entre 0 e 10 e calcula a média, aceitando ponto ou vírgula como separador decimal.  
**Conceitos aplicados:** Entrada de dados com `Scanner`, substituição de vírgula por ponto, cálculo de média.

---

## Requisitos

- Java JDK 11 ou superior
- Editor de código (VS Code, IntelliJ, Eclipse, etc.)
- Terminal para compilar e executar os arquivos `.java`

## Como Executar

1. Compile o código:
   ```bash
   javac Task_X.java
   
2. Execute:
   ```bash
   java Task_X

> Substitua Task_X pelo nome da tarefa desejada, como Task_1, Task_2, etc.
